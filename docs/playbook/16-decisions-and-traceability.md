## Invariant checklist for implementation reviewers

- No source changes from this documentation delivery; historical audit never relabeled to imply new modules exist.
- Same project/assignment/claim/evidence/decision IDs used by Trust and Steward, with One context snapshot references.
- Accepted nursery supply cannot set a planting bit; context/checks cannot set survival approval.
- Human approval references exact content/evidence/policy/check/field-report versions; revisions require re-review.
- Policy requirements determine eligibility, not UI defaults or whichever inspections happen to exist.
- Human authorization, chain-confirmed authority and simulated settlement have separate data/status/UI and notifications.
- Contract guards demonstrably work under direct RPC calls; no universal audit publisher bypass sets milestone or monetary authority.
- Stable obligation key deduplicates economic outcome across retries/reissued authorizations; histories/corrections retained.
- No email/SMS sent, real financial transfer, cryptocurrency asset, NFT or carbon credit.
